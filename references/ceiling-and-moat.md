# 瓶颈与竞争：原创诊断工作法

理论入口见 [sources.md](sources.md)，以下为独立运营应用。

## A. 分解增长放缓

先统一活跃事件与周期，再核算：期末活跃 = 期初活跃 + 新激活 + 重新活跃 − 不再活跃。类别必须互斥，不混入累计注册数。

按局部网络、新旧人群、供需两侧与渠道查看。整体变差可能是新增弱网络占比上升；整体不变也可能掩盖关键群体流失。

| 待检验原因 | 有区分力的证据 | 先做什么 |
|---|---|---|
| 覆盖接近上限 | 可触达人群减少、重叠增加，旧群体仍有稳定结果 | 核查去重触达和未服务细分 |
| 渠道或信息失效 | 相近人群响应下降或价格升高 | 固定人群试验信息/渠道，并看激活质量 |
| 匹配或体验退化 | 等待变长、取消增加、找不到合适对象 | 回看失败会话，试验分组、排序或履约改善 |
| 新人涌入造成规范冲突 | 老人贡献下降、新人留存也差，冲突有聚集 | 改变引导、分层交流或主持方式 |
| 注意力和收益失衡 | 曝光集中，新合格供给迟迟无结果 | 测新供给首次机会与质量结果 |
| 垃圾或虚假行为增加 | 有效内容比例下降、举报或退款上升 | 抽样标注，再调准入、分发或治理 |
| 规则变化或关键角色外流 | 收益、流失、跨平台行为共同变化 | 访谈流失与留下人群，验证替代规则 |
| 外部变化或产品故障 | 行业同步波动、版本异常、季节性 | 先做业务及技术排查 |

同时查看被帮助与可能受损的角色。例如准入变严可能减少垃圾，也可能挡住优质新人。不能只看总互动或平均收益。

履约中断、产品故障或关键角色大量退出要优先处置；普通获客效率优化可后置。真实线上变更仍服从已有授权。

## B. 围绕可兑现价值竞争

固定竞争发生的网络单元和服务场景，不用全国注册量与单城活跃供给互比。

| 比较项 | 我方 | 对手 | 证据与日期 |
|---|---|---|---|
| 关键角色及诉求 | | | |
| 有效供需、匹配结果 | | | |
| 获得结果的时间与质量 | | | |
| 关键角色净收益、负担和风险 | | | |
| 多平台使用及迁移障碍 | | | |
| 尚未满足的人群或场景 | | | |
| 外部渠道、接口或规则依赖 | | | |

资料不足标注未知，先收证据，不从品牌知名度推断结果。

无法访问对手日志时，可交叉核对用户自愿提供的任务记录、访谈和我方行为变化，分别标记证据性质；无法观察不能填成零。负责人试用不等于团队迁移，少量访谈也不能直接作为竞品转化或留存的分母。

- **进入者**：选能明显改善结果、团队能服务的细分单元，验证局部供需与保留能力；也判断未来扩展路径。
- **已有平台**：找最影响稳定的角色及未满足诉求，改善结果、收益或使用负担；比较成本与持续流失的影响。
- **补贴**：明确对象、资格、预算上限、滥用识别与撤除后观察窗口；补贴期份额不能代表可持续份额。
- **捆绑分发**：分别测触达、尝试、核心任务与持续使用。分发能力之外，还要验证关系和使用价值是否进入新网络，以及原产品是否受损。
- **借用已有渠道**：确认合法可用入口；检查渠道中断后的获客及留存，不能把外部流量永久稳定当作前提。

保留相反解释，如价格更低、季节变化或我方故障；有证据才说对手削弱了网络。支持成熟关键角色时，也关注新人获得首次机会的可能性，避免只优化头部短期结果。

## C. 更新判断

记录原假设、执行差异、窗口、结果、成本与意外影响。决定继续、修改、停止或扩大，说明适用边界。

短期回升不证明护城河形成。分别验证「当前更有吸引力」「更难替代」「关键角色退出会连锁影响其他人」。
