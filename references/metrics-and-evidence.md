# 指标与证据规范

以下为本 skill 新增的测量约定，不是书中给定公式或标准。选能回答问题的少量指标，无须全部计算。

## 统计合同

每项注明：网络单元、用户角色、有效事件、时区、窗口、分子、分母、去重键、排除规则、数据来源。缺失值不是零；分母为零输出 N/A；窗口未结束的样本标记未成熟。

注册、激活和完成核心价值的用户可能不同，分别报告。多个单元按原始分子和分母汇总比率，同时保留局部结果，不直接平均百分比。

“合格回答”“完成交付”等涉及质量判断时，说明由谁、依据什么标准判定，试验前后保持一致；抽样复核分歧，不能只用事件发生次数代替质量。实验开始前固定口径、纳入规则和决策条件；中途改变时记录为新一轮，不追着结果修改成功标准。

| 指标 | 建议定义 | 防止误读 |
|---|---|---|
| 首次价值达成率 | 指定窗口内首次完成价值事件的新用户 / 同期有完整窗口的合格新用户 | 分母包含进入后无动作的人，规则变更需重算 |
| 互动/匹配成功率 | 承诺窗口内获合格结果的有效请求 / 有完整窗口的全部有效请求 | 区分请求级与用户级，定义取消和重复请求规则 |
| 首次结果耗时 | 从提交需求到首个合格结果的时间，报告中位数和高分位数 | 无结果者单列，不能从耗时样本中消失 |
| 分角色留存 | 起始队列在预定后续窗口发生价值事件的人 / 已成熟的原始队列人数 | 说明注册、激活还是贡献队列，不能用当期活跃作分母 |
| 有效供给 | 指定场景、时段内合格、可发现且有剩余承接能力的供给 | 注册卖家、累计内容不等于可用供给；关注质量与利用率 |
| 人工依赖 | 纳入范围内全部请求的人工分钟 / 最终成功结果数，另报每请求工时和介入比例 | 包含失败处理工时；先核对“每单”的分母；后台代办不算自主行为 |
| 邀请激活产出 | 某邀请者队列带来的去重且完成价值事件的新用户 / 原始邀请者人数 | 固定窗口、归因、重复邀请归属，不外推指数增长 |
| 每结果贡献 | 归属于有效结果的收入减直接可变成本，再除有效结果数 | GMV不是收入，列清补贴、支付、服务等费用是否已计入 |
| 关键角色净收益 | 实得收入减可归属成本，同时报告耗时或产出机会 | 平均值可能掩盖新人、弱区域或低分位群体受损 |

### 虚构计算示例

同口径完整窗口下，网络 A 有 80/100 次请求成功，B 有 2/10 次成功。整体是 82/110 = 74.5%，不是 (80%+20%)/2 = 50%。同时展示两组，以免掩盖 B 的问题。

## 获客回路估算

来自同一队列、同一窗口并处理去重与归因时：

`每名原始用户带来的有效新用户 ≈ 人均独立邀请对象数 × 接受率 × 接受后价值达成率`

直接观测去重后的有效新用户通常更可靠。该估算不是通用 K 值标准；未考虑生命周期、多次邀请、流失、延迟和饱和时，不能外推长期增长。传播也不能独立证明参与者获得更多价值。

## 证据强度

1. **机制假设**：能解释路径，尚无观测。
2. **行为观测**：观察到互动和结果，仍有其他解释。
3. **比较证据**：可比队列或网络有差异，说明选择偏差及共同变化。
4. **更强因果支持**：可行时按网络分组、分批推出或时间切换，处理相互影响、周期和残留效应。

用户相互影响时，按个人随机分组可能干扰；考虑可隔离的网络单元。单元少或无法隔离时说明限制，不伪造统计显著性。

按基线、可接受的最小变化、频率和误判成本规划样本、周期。缺信息先测量；固定人数、固定 7 天或“行业平均值”都不能自动满足要求。

## 目标、约束与退出

选一个表达主要用户价值的主指标，配以相关约束，如关键角色留存、投诉、取消、成本、人力负担。

数值注明是用户要求、数据推导，还是尚待检验的目标假设。未知数值列确定方法与责任角色，不用貌似精确的经验数字填空。

停止可由预算耗尽、体验受损、关键假设被否定触发。未观察到改善但样本不足时，区分继续采样与停止投入。

## 如需倒推增长目标

使用数学定义，不照搬案例公式：年度增长倍数 = (终值/正值初值)^(1/年数)，CAGR = 年度增长倍数 − 1。初值为零不可计算，应先定义正值基期或使用绝对增量。均速仅描述目标要求，不证明可达；收入目标也不能代替网络健康。
