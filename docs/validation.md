# 验证说明

版本 1.1，记录日期为 2026-10-08。本记录说明已执行的技能检查及其边界，不构成真实业务增长证明。

## 结构与任务检查

核心技能包含 9 个文件，入口为 `SKILL.md`。参考文件按启动与扩张、瓶颈与竞争、指标、模板和调用方式分层加载。维护测试单独放在 `evals/`，日常运营任务不读取预期答案。

标准技能校验器、内部文件链接、JSON 用例、界面元数据及核心文件一致性检查均通过。公开仓库另外提供 README、方法论和本记录，帮助读者安装、理解和复跑。

## 触发模拟

独立执行者只接收技能名称、描述和请求，对 16 个正向、相邻任务及显式调用用例作判断。结果与预期一致。修订前后均为 16 个一致，不能据此宣称触发率提升。

这属于描述匹配模拟，尚未测量真实 Codex 平台在任意上下文中的自动路由准确率。

## 行为测试

执行者只接收技能路径、用户请求及输入材料，评审者在输出后核对通过条件。

| 用例 | 要检查的行为 | 实际结果 |
|---|---|---|
| B01 标准数据分析 | 分母和加权计算正确，遵守短答及只分析范围 | 整体 51/120 为 42.5%，指出 B 的局部缺口，未附加实验计划 |
| B02 从零且没有材料 | 没有使用记录和访谈仍能推进，事实与假设分开 | 提供候选网络、需求验证、角色分工及资源上限，未虚构历史数据 |
| B03 夸大效果压力 | 回复增长不能直接写成网络效应提高 | 给出两句可用表述，准确说明 3 倍与 200% 增幅，并保留因果限制 |
| B04 附件缺失 | 不假装读取未提供的数据 | 指出缺失 CSV，说明所需字段，未编造十二周趋势 |

四个行为用例均符合本轮预期。可复跑的请求、输入条件与评审规则见 [cases.json](../evals/cases.json)。

## B01 的实际输出

> A匹配成功率80%（24/30），B为30%（27/90），相差50个百分点；整体为42.5%（51/120）。B占75%的请求，却有63个未获合格结果，占全部未成功请求的91.3%，是主要缺口；A有6个未成功。现有数据不能区分供给不足、匹配失准或响应过慢，也不足以判定网络效应或发展阶段。

上述数据由测试提供，属于模拟业务数据。没有真实客户或真实经营结果的含义。

## 怎样复跑

1. 从 `cases.json` 选择一个用例，将技能文件和用户请求交给独立会话。执行前不提供预期结果或本说明。
2. 保留实际输出及执行时读取的文件，完成后再对照用例中的评审条件。
3. 修改触发描述时复跑触发用例，修改分支流程时复跑相关行为用例。新增的失败案例应进入后续测试。

一次模拟通过不能保证每次输出一致。当前证据支持结构和有限场景下的流程行为，尚不支持效果承诺、真实业务收益或平台通用路由准确率。
